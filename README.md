# Minigames

A browser minigame built with TypeScript for the [RSS School](https://rs.school/) qualifying stage, following the [common project requirements](https://github.com/rolling-scopes-school/qualifying-stage/blob/main/tasks/minigames/common-project-requirements.md).

## Stack

- TypeScript
- Webpack (dev server + production build)
- ESLint + Prettier
- Husky + commitlint ([RS School git convention](https://rs.school/docs/git-convention))

## Scripts

- `npm start` — run the dev server at http://localhost:3000
- `npm run build` — production build into `dist/`
- `npm run lint` / `npm run lint:fix` — lint TypeScript files
- `npm run format` / `npm run format:check` — format with Prettier
